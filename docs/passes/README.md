# Pass lifecycle

Start at [START](../../START.md). Only [active](active/) briefs are actionable; consult [INDEX](INDEX.md) before selecting one. Keep active briefs small and scoped. Durable truth belongs in issues, backlog, ADRs and PROGRESS.

On merge/issue close, move the brief and its prompt to archive/ and mark INDEX done. When replaced, archive and mark superseded. Archive rather than delete. Never execute an archived brief as a current task. Handoffs use the same lifecycle under [backlog/handoffs](../backlog/handoffs/README.md).
