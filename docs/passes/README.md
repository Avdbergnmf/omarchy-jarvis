# Pass lifecycle

Start at [START](../../START.md). Only [active](active/) briefs are actionable; consult [INDEX](INDEX.md) before selecting one. Keep active briefs small. Durable truth belongs in issues, backlog, ADRs, PROGRESS, and [assignments](../assignments/QUEUE.md).

On merge/issue close, move the brief and its prompt to archive/ and mark INDEX done. When replaced, archive and mark superseded. Archive rather than delete. Never execute an archived brief as a current task.

Day-to-day work orders: [assignments/QUEUE](../assignments/QUEUE.md). Alex prompts: [assignments/prompts](../assignments/prompts/README.md).
